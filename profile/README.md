# MiiCaLabs

MiiCaLabs is an independent product lab led by **Harivonjy Rica**, a Certified Zoho Developer and software engineer.

I build cross-platform software with **JavaScript**, **Python**, and **Rust**, with a strong focus on Zoho developer tools, workflow automation, AI-assisted systems, and domain-specific products across multiple areas.

Most of the work starts from a real operational problem: scattered scripts, repeated manual steps, hard-to-track release notes, or critical information that needs to stay available offline. The goal is to turn those problems into tools that fit the way people already work.

## Public Projects

| Project | Focus | What it does |
|---|---|---|
| [Zentra](https://github.com/MiiCaLabs/zentra) | Zoho script intelligence | A cross-browser extension for Zoho developers. It helps teams find the right scripts in context, reuse logic, and avoid copy-paste workflows. |
| [Zerra](https://github.com/MiiCaLabs/Zerra) | Zoho widget generation | An AI-native builder for Zoho widgets. It generates TypeScript-strict, CSP-clean widgets and checks manifests, API usage, and packaging before release. |
| [This Week in Zoho](https://github.com/MiiCaLabs/this-week-in-zoho) | Zoho ecosystem publishing | A curation system for public Zoho release notes. It normalizes updates, gives a human curator an admin inbox, then publishes weekly editions by email and web archive. |
| [MiiCaMed Pocket](https://github.com/MiiCaLabs/MiiCaMed-Pocket) | Medical reference app | An offline-first mobile app for healthcare professionals in Madagascar, with quick access to therapeutic protocols and drug references. |
| [Project Ideas](https://github.com/miica-org/project-ideas) | Product research | Working notes and system-design briefs for future products, including healthcare, education, and smaller niche systems. |

## How We Build

- Start from the workflow, not from the technology stack.
- Build for the target platform, especially Zoho and mobile/offline environments.
- Use AI where it makes expert work faster, more reusable, or easier to validate.
- Keep systems small, clear, and maintainable enough for real operational use.

## Founder

**Harivonjy Rica** works across product design, software engineering, developer tooling, and automation. His work combines Zoho platform experience with cross-platform application development in JavaScript, Python, and Rust.

## Areas of Interest

- **Zoho developer experience**: tools that make Deluge, widgets, extensions, and platform integrations easier to build, reuse, and maintain.
- **Script and widget intelligence**: systems for discovering existing logic, generating platform-native components, and validating code before release.
- **AI-assisted workflows**: practical AI features that help with research, generation, review, repair, and repetitive operational tasks.
- **Cross-platform applications**: mobile, desktop, web, and browser-extension software built with JavaScript, Python, and Rust.
- **Knowledge systems**: products that collect, normalize, organize, and publish trusted information for specific professional communities.
- **Offline-first and local-context tools**: software designed for environments where connectivity, device constraints, language, and field conditions matter.
- **Healthcare, education, and business operations**: domain-focused products that support real work instead of abstract demos.
- **Product research and system design**: early-stage briefs, architecture notes, workflow maps, and experiments for future MiiCaLabs products.
