# MiiCaLabs

MiiCaLabs is an independent product studio building Zoho developer tools, offline-first software, and practical automation products.

We work where business operations meet software engineering: Zoho CRM workflows, developer tooling, cross-platform applications, and AI-assisted systems that keep people in control.

MiiCaLabs is founded by [Harivonjy Rica](https://github.com/h-rica), a software engineer and Certified Zoho Consultant based in Madagascar.

## What we build

- **Zoho developer tools:** extensions, Catalyst applications, integrations, automation, and data-quality tooling
- **Cross-platform software:** desktop, web, mobile, and command-line tools built with TypeScript and Rust
- **Offline-first products:** software for environments where connectivity, local data, and device constraints matter
- **AI-assisted workflows:** focused AI features for research, review, generation, and operational work

## Selected products
